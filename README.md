## 🌟 What is IGNITION?

In Pakistan, buying your first car (Suzuki Alto 660cc, Cultus, Swift, Toyota Yaris, or Honda City) is a milestone of independence, safety, and family dignity. 

Traditional budgeting apps in USD don't understand the reality of saving in Pakistani Rupees (PKR) amid inflation and daily lifestyle leaks. **IGNITION** fixes this with a psychological motivation engine that provokes daily discipline, celebrates progress milestones, and visualizes the exact countdown to turning your dream car's ignition key.

---

## ⚡ Key Features

- **🏎️ Tachometer Speedometer Gauge**: Dynamic animated SVG gauge with sweeping needle, live percentage ticker, and redline victory zone.
- **💰 Exact Cash Calibration**: Clean input with real-time comma separators (hundreds, thousands, and lacs: `1,35,000` / `8,75,000`) and zero leading-zero bugs.
- **🛑 The Impulse Stopper Weapon**: Enter an impulse expense (e.g., ₨ 4,500 on café dining) to calculate exactly how many **extra days** you will have to walk or ride in 44°C heat, with a 1-click **"Divert to Car Vault"** button!
- **🏁 4-Stage Physical Car Roadmap**:
  - **Stage 1 (25% - ₨ 2,18,750)**: *Blueprint & Chassis*
  - **Stage 2 (50% - ₨ 4,37,500)**: *Engine Block & Turbo*
  - **Stage 3 (75% - ₨ 6,56,250)**: *Alloy Wheels, Interior & AC*
  - **Stage 4 (100% - ₨ 8,75,000)**: *Ignition Keys in Hand!*
- **🔥 Daily Dream Fuel & Audio Synthesizer**: Curated provocative quotes (Hardcore, Visionary, and Stoic personas) with offline synthesized sports car engine rev sound FX and celebratory confetti.
- **🔐 Driver Authentication & Isolated Data**: Each driver has their own private account and local storage.
- **👑 Stealth Creator Portal**: Secret access for the creator via `Ctrl + Shift + A` or footer trigger with master passcode verification (`ignition2026`).
- **🎨 Midnight Cockpit & Clean Light Modes**: Obsidian dark cockpit with glowing cyan/amber accents + minimalist light mode.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Danishthinks/ignition.git
cd ignition
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Effects**: Canvas Confetti, Web Audio API (zero audio file dependencies)
- **Icons**: Lucide React
- **Currency Support**: Pakistani Rupee (PKR) formatted in hundreds, thousands, and lacs (`en-IN` / `en-PK`)
